VOICECAMPUS — FRONTEND PROJECT

Files
- index.html: application structure
- style.css: responsive visual design and themes
- script.js: interactions and LocalStorage data handling

How to run
1. Extract the ZIP file.
2. Open the voicecampus folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

Features
- Overview dashboard and summary statistics
- Submit feedback anonymously or with a name
- Categories, campus area and message fields
- Feedback inbox with search and filters
- Demo status updates
- Category and status insights
- Light and dark theme
- Responsive layout for desktop and mobile
- LocalStorage persistence

Important limitations
This is a frontend-only demonstration. LocalStorage is specific to the browser and device being used. There is no server, shared database, real user authentication, or actual institutional admin account. The status selector is included to demonstrate an administrative workflow, not to provide secure access control. The sample submissions can be cleared by clearing the browser's site data.
